# Embedded_Systems_Nick_Savage_Final_2W_Robot_Report
Final Documentation for the 2 Wheer and 3 Wheel Robot

This project served as the final project for the 2026 Embedded Systems course. Students were tasked with demonstrating the cumulative skills developed throughout the quarter by designing and building both a two-wheeled and three-wheeled robot, each running on a custom-designed PCB.

The project was structured in phases. Students first created a conceptual block diagram, then designed a PCB containing all necessary components to support an STM32 microprocessor. Once the design was finalized, students soldered and assembled the board before moving on to robot construction and programming.

Through this project, students explored the full embedded systems development cycle, from PCB design and firmware programming to physical assembly and mechanical design using the STM32 as the central processing unit.
